SEC 01 Introduction & Problem Domain

EduPredict AI is an Explainable Artificial Intelligence and Learning Analytics platform engineered for higher education institutions. As university engineering curricula become increasingly rigorous, student failure rates in foundational analytical courses present severe institutional challenges. EduPredict AI resolves this challenge by operating as an integrated, real-time Early Warning System (EWS), synthesizing 9 core academic features into risk classification, percentage grade forecasting, exact XAI attribution, and counterfactual scenario simulation.

SEC 02 Motivation & Need

Limitations of Traditional Monitoring

  • Post-Mortem Evaluation: Relies on final exams, leaving zero lead time for remedial support.
  • Siloed Signals: Attendance, lab assignments, and tests exist in disconnected spreadsheets.
  • Black-Box Models: Existing ML tools output probabilities without explaining reasons.

The EduPredict AI Solution

  • Proactive 4-Week Detection: Predicts trajectory early using continuous formative signals.
  • Exact Mathematical XAI: Decomposes predictions into positive and negative drivers (βi · zi).
  • What-If Goal Setting: Enables students to test habit changes and observe score deltas.

SEC 05 Problem Statement

Higher education institutions face critical challenges in identifying and mitigating student academic risk due to the lack of integrated, real-time diagnostic systems. Traditional academic monitoring is predominantly reactive, evaluating outcomes only after summative examinations. Existing solutions often function as opaque black boxes that fail to provide transparent feature explanations, do not allow counterfactual simulation of habit improvements, and lack structured closed-loop intervention mechanisms for faculty advisors.

SEC 06 Solution Proposed

EduPredict AI resolves this challenge through an integrated 5-tier architecture: (1) Dual supervised ML pipelines for risk classification and continuous grade forecasting; (2) Exact linear XAI attribution (contrib_i = βi · zi); (3) Counterfactual What-If scenario simulation (Δy); (4) Deterministic multi-tier recommendation engine; and (5) Classroom topic diagnostic and intervention management console.

SEC 07 Approach & ML Methodology

Standardization: z_i = (x_i - μ_i) / σ_i Continuous Score Regression: y = β_0 + ∑ β_i · z_i Exact Linear XAI Attribution: contrib_i = β_i · z_i ⇒ y = β_0 + ∑ contrib_i (Error = 0.00000) What-If Delta: Δy = y_scenario - y_baseline = ∑ β_i · ((x_i,scen - x_i,base) / σ_i)

def train_logistic_regression(X_train, y_train):
    pipeline = Pipeline([
        ('scaler', StandardScaler()),
        ('classifier', LogisticRegression(solver='lbfgs', max_iter=1000, random_state=42))
    ])
    pipeline.fit(X_train, y_train)
    return pipeline

for idx, col in enumerate(FEATURE_COLUMNS):
    raw_val = float(X_input[col].iloc[0])
    z_reg = float(X_scaled_reg[idx])
    w_reg = float(reg_coefs[idx])
    contrib_reg = float(w_reg * z_reg)
    sum_reg_contribs += contrib_reg

    direction = "Upward Pull" if contrib_reg > 0.01 else ("Downward Pull" if contrib_reg < -0.01 else "Neutral")

    feature_contributions.append({
        "feature": col,
        "name": FEATURE_LABELS.get(col, col),
        "raw_value": round(raw_val, 2),
        "standardized_value": round(z_reg, 3),
        "coefficient": round(w_reg, 3),
        "contribution": round(contrib_reg, 3),
        "direction": direction
    })

VIVA Key Viva Voce Questions & Code-Grounded Answers

Q1: Why choose Logistic and Linear Regression over Deep Learning?
Answer: In educational early warning systems, interpretability is essential. Linear and Logistic Regression pipelines allow exact mathematical feature attribution (contrib_i = βi · zi) with zero reconstruction error. On our 9-feature dataset, Linear Regression achieved R² = 0.984 (MAE 1.61%) and Logistic Regression achieved 93.00% accuracy, matching Random Forest baselines (R² = 0.975) while providing full mathematical transparency.

Q2: How do you guarantee there is no data leakage?
Answer: (1) In ml/dataset.py, assertions ensure final_score is absent from feature matrix X; (2) StandardScaler is encapsulated inside Scikit-Learn Pipeline objects, fitting scaling parameters solely on training folds; (3) 5-fold cross-validation fits the pipeline anew on each fold.

Q3: How does What-If simulation avoid model retraining?
Answer: In backend/services/what_if_service.py, the frozen model executes inference on both baseline and scenario profiles. Automated test test_18_what_if_does_not_retrain_model asserts that model SHA-256 hashes and weights remain 100% immutable.

Q4: What is the significance of your Confusion Matrix?
Answer: On the N=100 test set, our model achieved 100% recall on High-Risk students (16/16 correctly identified) with zero false negatives. All 7 misclassifications occurred across the Medium/Low boundary.
