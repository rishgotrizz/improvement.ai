Applied Mathematics-I (AM-I) Behind the Prediction

First-year mathematical foundations: Statistics, linear regression, correlation, and gradient descent

📐 Viva Reference: How Math Powers EduPredict

Descriptive statistics and Pearson correlation formulas are implemented in Phase 3 (EDA). Supervised Linear Regression score estimation and Logistic Regression classification are fully implemented in Phase 4 (AI/ML).

1. Descriptive Statistics (Implemented in Phase 3)

Implemented in Phase 3
Arithmetic Mean (μ):
μ = (1 / n) * Σ xᵢ
Used to summarize average attendance, study hours, and final score.
Variance (σ²):
σ² = (1 / n) * Σ (xᵢ - μ)²
Measures data spread around the mean.
Standard Deviation (σ):
σ = √(Variance)
Quantifies dataset variability.

2. Pearson Correlation Coefficient (Implemented in Phase 3)

Implemented in Phase 3
Pearson Correlation Formula (r):
r = Σ[(xᵢ - x̄)(yᵢ - ȳ)] / √[Σ(xᵢ - x̄)² * Σ(yᵢ - ȳ)²]
Quantifies linear association (-1.0 to +1.0) between features (e.g. attendance ↔ final score).
Interquartile Range Outlier Method (IQR):
IQR = Q3 - Q1 | Bounds = [Q1 - 1.5*IQR, Q3 + 1.5*IQR]
Identifies potential statistical outliers in the dataset.

3. Linear Regression Score Prediction Formula (Implemented in Phase 4)

Implemented in Phase 4 ML
y = β₀ + β₁x₁ + β₂x₂ + β₃x₃ + ... + βₙxₙ
Variable Mapping:
  • y = Predicted Semester Percentage Score (%)
  • x₁ = Lecture Attendance Rate (%)
  • x₂ = Weekly Self-Study Hours
  • x₃ = Assignment Average (%)
  • x₄ = Previous Semester Percentage (%)
Coefficient Weights (β):
  • β₀ = Y-intercept (Base score bias constant = 75.25)
  • β₁ = Weight per standardized unit of attendance (+3.01)
  • β₂ = Weight per standardized unit of study (+4.64)
  • β₃ = Weight per standardized unit of assignment score (+2.33)

4. Individual Feature Contribution Formulation (Implemented in Phase 5)

Implemented in Phase 5

Individual student feature explanations decompose the total prediction into feature-level contributions derived from fitted StandardScaler parameters ($\mu_i, \sigma_i$) and linear model weights ($\beta_i$):

zᵢ = (xᵢ - μᵢ) / σᵢ | contributionᵢ = βᵢ × zᵢ | ŷ = β₀ + Σ contributionᵢ
Demonstration Note: Summing all 9 individual feature contributions ($\sum \text{contribution}_i$) with model intercept ($\beta_0$) reconstructs the predicted score ($\hat{y}$) within exact numerical tolerance ($< 10^{-5}$).

5. Mean Squared Error & Gradient Descent Optimization

Conceptual Documentation

During model training, regression weights ($\beta_j$) were fitted using Ordinary Least Squares / Gradient Descent to minimize Mean Squared Error (MSE) loss:

MSE = (1 / n) * Σ (yᵢ - ŷᵢ)² | θⱼ := θⱼ - α * (∂ / ∂θⱼ) J(θ)
Where α represents learning rate, and J(θ) is the cost function.

6. What-If Scenario Simulation Mathematics (Implemented in Phase 6)

Implemented in Phase 6

The What-If Scenario Simulator evaluates linear score differences between baseline and hypothetical standardized input states:

Δŷ = ŷ_scenario − ŷ_baseline = Σ βᵢ ( zᵢ,scenario − zᵢ,baseline )
• z-Score Transformation: zᵢ = (xᵢ − μᵢ) / σᵢ
• Mathematical Interpretation: Δŷ represents a pure mathematical shift in model output projections without model retraining or establishing real-world causal causality.
