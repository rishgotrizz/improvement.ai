System Pipeline

How EduPredict Processes Data

1. Data Input 9 continuous student academic attributes
2. Scaler Z-score standardization ($z_i = \frac{x_i - \mu}{\sigma}$)
3. AI Model Logistic Classifier & Linear Regressor
4. XAI Signals Feature contributions ($\beta_i \cdot z_i$)
5. Rules Engine Deterministic threshold priorities
6. Intervention Action items & progress monitoring
