1. Subject Priority Recommendation Logic (CPA)

Deterministic Rule Engine

EduPredict calculates a priority score for each course based on performance gap ($G_s$), attendance deficit ($A_d$), and assignment gap ($W_a$). Courses are then ranked using Python's built-in sorting functionality (`sort()` / TimSort algorithm, $O(n \log n)$ worst-case time complexity):

def calculate_subject_priority(subjects, overall_avg): # Step 1: Linear scan to compute performance gaps and priority scores - O(n) prioritized_list = [] for s in subjects: gap = overall_avg - s['score'] att_penalty = max(0, 75 - s['attendance']) ass_deficit = max(0, 80 - s['assignments']) priority_score = (0.50 * gap) + (0.30 * att_penalty) + (0.20 * ass_deficit) if priority_score > 7.0: category = "HIGH"; rec_mins = 45 elif priority_score > 3.5: category = "MEDIUM"; rec_mins = 30 else: category = "LOW"; rec_mins = 20 prioritized_list.append({ 'code': s['code'], 'score': priority_score, 'category': category, 'minutes': rec_mins }) # Step 2: Rank using Python's built-in sorting (TimSort algorithm) - O(n log n) prioritized_list.sort(key=lambda x: x['score'], reverse=True) return prioritized_list

🎓 Educational Algorithm Demonstration (CPA Viva Reference)

Academic Demonstration

For academic demonstration during viva examinations, below is an explicit implementation of Insertion Sort ($O(n^2)$ worst-case time complexity, $O(1)$ auxiliary space) illustrating step-by-step element swap mechanics:

def academic_insertion_sort(arr): """Educational explicit sorting loop for CPA viva demonstration.""" for i in range(1, len(arr)): key_item = arr[i] j = i - 1 while j >= 0 and arr[j]['score'] < key_item['score']: arr[j + 1] = arr[j] j -= 1 arr[j + 1] = key_item return arr

2. Computational Efficiency & Architecture Principles (COA)

EduPredict documents technical time and space complexity across dataset parsing and statistical aggregation:

In-Memory Dataset Space — O(n)

When loaded into RAM, the 500-record Pandas DataFrame occupies $O(n)$ memory space (~120 KB RAM), enabling fast vectorised arithmetic.

Single-Pass Aggregation — O(n) Time

Descriptive statistics (Mean, Sample Variance, Min/Max) are computed in linear $O(n)$ time complexity in a single scan across feature arrays.

In-Memory Cache Lookup — O(1) Time

_CACHED_EDA_RESULT in eda/analysis.py provides approximately $O(1)$ dictionary key retrieval time. The memory cost is $O(k)$ proportional to the result payload size.
